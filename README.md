# Александр и Катрина — первый экран

## Файлы

- index.html — разметка первого экрана.
- css/style.css — вся стилизация, адаптация и анимации; комментарии на русском.
- images/hero-mobile.png — прозрачная композиция с надписями, 791×1363.
- images/velvet-mobile.webp — бархатный фон.
- images/hero-desktop.webp — desktop-сцена без стрелки, 1672×941.
- images/scroll-down.svg — отдельная анимированная стрелка для обоих экранов.

В HTML пути начинаются с images/, а в CSS — с ../images/, поскольку CSS лежит в подпапке.

## Как устроено

До 1024px: бархат на секции, прозрачная картинка поверх, отдельная анимированная стрелка.
Картинка вписывается по ширине и высоте, чтобы имена и дата оставались видны.
На низком экране по бокам будет больше бархата: это осознанный компромисс ради целой композиции.
От 1024px: единая desktop-картинка фоном. Надписи уже нарисованы на ней. Стрелка расположена поверх отдельным SVG и анимируется.
Руки на desktop остаются частью фона.

Для desktop выбрано contain: вся сцена остаётся видимой. При отличии пропорций экрана
от изображения могут быть видны области дополнительного бархатного фона и их границы.


Сейчас реализован только hero. Стрелка декоративная, ссылки на несуществующие блоки нет.
